# Proyecto Java — Sistema de Login en Consola

Este proyecto es una aplicación en Java que implementa un **sistema básico de registro, inicio de sesión y listado de usuarios** usando la consola. Está diseñado como ejemplo didáctico para aprender estructuras de datos, POO, manejo de archivos y buenas prácticas en Java.

---

## 🚀 Características

- Registro de usuarios con validación de correo único.
- Inicio de sesión con comparación segura de contraseñas (hash SHA-256).
- Listado de usuarios registrados.
- Persistencia en archivo `users.csv`.
- Código modular dividido en 3 clases:
  - `User`
  - `UserRepository`
  - `Main`
